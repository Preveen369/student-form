# 📝 Student-Form – A Student Registration Web App

![Platform](https://img.shields.io/badge/Platform-Web-blue.svg)
![Tech](https://img.shields.io/badge/Frontend-HTML%20%7C%20CSS-orange.svg)
![Language](https://img.shields.io/badge/Language-JavaScript-yellow.svg)
![License](https://img.shields.io/badge/License-MIT-lightgrey.svg)

**Student-Form** is a static web application designed for student registration, built using HTML, CSS, and JavaScript. It allows users to input student details such as name, age, grade, and contact information, and stores the data in the browser's localStorage. The app provides a simple and intuitive interface for managing student records locally.

---

## 🚀 Features

### 🏠 Welcome & Main Page
- Serves as the initial landing page introducing the app’s purpose.  
- Provides a form for entering student details.

### 📋 Student Registration Form
- Displays a form to input student information like name, age, grade, and contact details.  
- Allows users to submit and view student records stored in localStorage.

---

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript  
- **Storage**: Browser's localStorage

## 🧪 Installation & Setup

### 📋 Prerequisites
- A modern web browser (e.g., Chrome, Firefox)

### 🧑‍💻 Steps to run
1. **Clone the repository**
   ```bash
   git clone https://github.com/Preveen369/student-form.git
   cd student-form
   ```

2. **Open the app**
   - Open `index.html` in your web browser to start using the student registration form.
