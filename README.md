# 📝 Student-Form – A Student Registration Web App

![Platform](https://img.shields.io/badge/Platform-Web-blue.svg)  
![Tech](https://img.shields.io/badge/Frontend-HTML%20%7C%20CSS-orange.svg)  
![Language](https://img.shields.io/badge/Language-JavaScript-yellow.svg)  
![License](https://img.shields.io/badge/License-MIT-lightgrey.svg)

**Student-Form** is a static web application designed for student registration, built using HTML, CSS, and JavaScript. It allows users to input student details such as name, age, grade, and contact information, and stores the data locally or in a backend like Firebase Firestore. The app provides a simple and intuitive interface for managing student records.

---

## 🚀 Features

### 🏠 Welcome & Main Page
- Serves as the initial landing page introducing the app’s purpose.  
- Provides a form for entering student details.

### 📋 Student Registration Form
- Displays a form to input student information like name, age, grade, and contact details.  
- Allows users to submit and view student records.

---

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript  
- **Database**: Browser's LocalStorage

## 🧪 Installation & Setup

### 📋 Prerequisites
- A modern web browser (e.g., Chrome, Firefox)  
- Firebase CLI (optional, if deploying with Firebase)

### 🧑‍💻 Steps to run
1. **Clone the repository**
   ```bash
   git clone https://github.com/Preveen369/Student-Form.git
   cd Student-Form
   ```

2. **Open the app**
   - Open `public/index.html` in your web browser to start using the student registration form.

3. **(Optional) Deploy with Firebase**
   - Initialize Firebase: `firebase init`
   - Deploy: `firebase deploy`

🌐 Access your app live at: https://student-form-7aa78.firebaseapp.com/
